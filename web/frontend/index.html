Agentic OSINT Harness

Pick a company, a person, or a claim. The agent plans lines of enquiry, searches, reads what it finds, grades every publisher and every assertion on the Admiralty scale, weighs competing hypotheses by what disconfirms them, and reflects before committing to a verdict with a calibrated confidence. Every citation traces back to a document it actually retrieved. Source on GitHub.

A live investigation runs six phases and can loop back for more evidence, so it takes several minutes and a dozen model calls. The backend sleeps when idle, so the very first request may take up to a minute to wake it.
