Agentic OSINT Harness

Pick a company, a person, or a claim. The agent plans lines of enquiry, searches the live web, reads what it finds, grades every publisher and every assertion on the Admiralty scale, weighs competing hypotheses by what disconfirms them, and reflects before committing to a verdict with a calibrated confidence. Every citation traces back to a document it actually retrieved, live, while you watch. There is no offline stand-in on this path. Source on GitHub.

A live investigation runs six phases and can loop back for more evidence, so it takes several minutes and roughly a dozen model calls, shared across everyone visiting today. The backend sleeps when idle, so the very first request may take up to a minute to wake it.
